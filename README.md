This repository contains example of different important features of typescript.
TypeScript is a language created on the javaScript. TypeScript introduce many new features including type safety. 
There are 8 code snippet each focusing on a specific part of typescript:
return type with default, type alias with union, readonly tuple, generic type, Object filtering with interface, data modification using multiple generic types, access modifier in class with inheritance properties, Promise.
